# ETL Project

## Overview
This project demonstrates an ETL (Extract, Transform, Load) pipeline using Python.

## Technologies Used
- Python
- Pandas
- Azure SQL Database
- PyODBC
- SMTP Email
- Git & GitHub

## Project Workflow
1. Extract data from CSV
2. Transform the data
3. Save transformed data
4. Load data into Azure SQL Database
5. Send email notification
6. Generate logs

## How to Run
pip install -r requirements.txt
python run_etl.py
